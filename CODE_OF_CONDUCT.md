# Code of Conduct

Catification is a small, friendly project about pixel cats, and we'd like it to stay that way.

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: be kind, assume good intent, welcome newcomers, and keep criticism about the work, not the person.
Harassment and personal attacks are not tolerated.

To report unacceptable behaviour, contact the maintainer, [@Nikolsi](https://github.com/Nikolsi), on GitHub.
Reports are handled privately.
